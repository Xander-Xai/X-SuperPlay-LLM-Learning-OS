# M11 蒸馏 / 压缩 / Serving 与 M12 高级专题

## M11：模型进入应用前的完整链路

- **蒸馏**：教师生成软标签/伪标签/轨迹，学生学习；与简单合成数据的区别是训练目标、数据和教师信号的具体设计。
- **量化**：PTQ、QAT、权重/激活量化；比较精度退化、显存节省、支持算子。
- **LoRA 合并**：merge/unmerge、量化模型的兼容性、Adapter 版本追踪。
- **推理工程**：KV Cache、PagedAttention、Continuous Batching、Prefill/Decode、Speculative Decoding；vLLM 部署与服务性能。
- **Agent 集成**：Tool Parser、Chat Template、JSON Schema、引用正确率、任务回归和版本回滚。

**验收**：相同模型/输入/解码设置下，量化前后质量与性能对照；部署前后 Tool Call 与引用无回归。记录 TTFT/P95/Tokens-s/VRAM，绝不只比较单条推理速度。
