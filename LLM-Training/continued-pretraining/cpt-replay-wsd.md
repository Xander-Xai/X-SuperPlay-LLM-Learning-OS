# CPT / Mid-training：训练动力学与防遗忘实验

## 目标

在 16GB 单卡上做**可解释的短预算实验**，不要把实验目标设成短时间将 Qwen3-0.6B 训练成具备全面领域知识的专家。

## 一、三组对照

| 组别 | 初始化 | 数据 | 核心观测 |
|---|---|---|---|
| Base | 原始 Qwen3-0.6B-Base | 不训 | 域内/通用基线 |
| Domain | 相同 Base | 100% 领域 token | 领域表现与通用退化 |
| Replay | 相同 Base | 80% 领域 + 20% 通用 token | 对比遗忘程度 |

80/20 是预注册配比，不代表最优。对训练组控制训练 token 数、batch、sequence length、可训练参数、优化器、数据清洗级别和验证方式；记录采样概率和随机种子。若预算允许可加 50/50 作为敏感性分析。

## 二、学习率调度

**单独开展** Cosine vs WSD 对照（不要同时更换数据配比），尽量匹配累计 token、峰值学习率和 warmup。WSD 的 stable 段与 decay 时点需要明确记录；两者并无普遍优劣。

## 三、评估矩阵

| 类别 | 建议 |
|---|---|
| 域内文本 | 固定 held-out 的 CE/PPL |
| 通用文本 | 固定通用数据 CE/PPL（tokenizer 相同） |
| 域内任务 | 证据支持率、准确率、工具任务成功率 |
| 通用任务 | 小规模通用推理/语言子集作为辅助 |
| 训练动力学 | LR、梯度、Loss、吞吐、显存 |
| 防遗忘 | 相对 Base 的性能变化和置信区间（可行时） |

先对分词、样本长度和数据清洗做检查；小数据与小评测下性能波动可能来自随机性，不要做过强因果结论。

## 四、Go/No-go

有数据配比、训练预算、版本、曲线、域内与通用对照才算完成。**如果 Replay 没有改善，也应保留真实结果**。实验详细任务见 [02 CPT Replay](../experiments/02-qwen-cpt-replay/README.md)。
