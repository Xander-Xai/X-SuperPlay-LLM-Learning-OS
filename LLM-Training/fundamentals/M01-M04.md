## M03 Transformer 结构

完整张量追踪：input_ids [B,T] → embedding [B,T,D] → attention (Q,K,V heads) → position encoding → MLP → norm → hidden [B,T,D] → logits [B,T,V]。

必须解释：
- 为什么 Decoder-only 需要 causal mask？
- RoPE 在 Q/K 上如何引入相对位置关系？其 shape 和广播机制？
- RMSNorm vs LayerNorm；SwiGLU vs 普通 MLP；GQA 共享 KV 的含义。
- 训练期间的全序列 Attention 与推理的增量 KV Cache 的关系。
- 为什么使用 fused kernel / FlashAttention 影响 IO 和吞吐，但不改变模型训练目标？

## M04 Pretrain Loop

~~~python
for batch in loader:
    input_ids, labels = batch
    logits = model(input_ids)
    loss = causal_lm_loss(logits, labels)  # 注意 shift 与 ignore_index
    loss.backward()
    optimizer.step()
    optimizer.zero_grad(set_to_none=True)
    scheduler.step()
~~~

上面是**概念伪代码**，非 MiniMind 的可直接替换脚本；梯度累积、AMP、分布式同步、正确的 scheduler 调用时机、padding mask 均被省略。

训练记录：step、tokens_seen、train/eval loss、PPL（注意 BPE 的跨 tokenizer 不可直接比较）、梯度范数、学习率、吞吐、显存、checkpoint hash。

**Checkpoint 区分**：权重只够做推理/部分继续训练；精确恢复训练还需要优化器、scheduler、scaler（若有）、RNG、数据采样器状态及相关配置。
