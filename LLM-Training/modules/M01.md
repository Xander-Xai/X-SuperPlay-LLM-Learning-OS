## V3 深入：按当前需求直达本模块（不用先学完前面所有章）

**真实触发：** 在一次 QLoRA 训练 OOM/NaN 时如何判断是梯度、激活还是优化器状态？

### 机制：专业定义与输入/输出

反向传播是复合函数的链式求导；AdamW 使用梯度的一阶/二阶动量并将 weight decay 与梯度更新解耦。对于矩阵 X[B,T,D] 经过线性层 W[D,V]，logits[B,T,V]，交叉熵经 logits 回传至 W 与 X。

### 大白话：它为什么有用

大模型训练像工厂：参数是机器、梯度是每轮误差反馈、优化器状态是记住前几轮偏差的仪表板、激活是加工中暂存的半成品。OOM 可能由半成品占用，不是机器本身太大。

### 可执行学习任务（先证据后算法）

先在 CPU 用 2×3 的张量手算一处 softmax+CE 梯度，再用 autograd 做 finite-difference 梯度对照。改变 seq_len 而保持参数量不变，记录 allocated/reserved 与峰值差；没有 GPU 时只记录理论估算，不能填显存实测。

**失败注入 / 负例：** 反例：忘记 zero_grad 导致累积；全 labels=-100 导致 NaN；混合精度下发生溢出或梯度范数异常。针对失败先打印有效 label token 数、grad_norm、dtype 和 LR。
