## V3 深入：按当前需求直达本模块（不用先学完前面所有章）

**真实触发：** 为什么更长 Prompt 会显著增加 TTFT，而 GQA 能减少 KV Cache？

### 机制：专业定义与输入/输出

Self-attention 使用 QKᵀ 缩放、causal mask 和 softmax 对 V 加权；GQA 让多个 Query Head 共用较少 KV Head，减少生成阶段缓存的 K/V 元素。RoPE 编码相对位置信息，不是直接给 embedding 加固定位置值。

### 大白话：它为什么有用

Attention 像开会前检索笔记：每个 token 只允许查过去记录；KV Cache 像保存历史会议索引，避免每输出一个字就把整段会重新处理。

### 可执行学习任务（先证据后算法）

在 MiniMind 中记录 Q/K/V 的 [B,H,T,D]，断言修改未来 token 不影响前面位置；比较 MHA/GQA 理论缓存量并测一组固定的 Prefill/Decode 时间。注意模型权重、dtype 和上下文长度一致。

**失败注入 / 负例：** 反例：causal mask 方向反了导致未来泄漏；KV 缓存与位置偏移不一致；将 FlashAttention 误说成近似注意力或推理一定更快。
