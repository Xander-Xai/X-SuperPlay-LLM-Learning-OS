## V3 深入：按当前需求直达本模块（不用先学完前面所有章）

**真实触发：** 为什么 100% JSON Valid Rate 仍可能是很差的 Agent？

### 机制：专业定义与输入/输出

有效评估要区分语法、参数语义、工具实际执行、完整任务、证据支持和权限；训练与测试按任务家族隔离。模型能力评测同时考虑不确定性、抽样/长度/预算与负例。

### 大白话：它为什么有用

JSON Valid Rate 只像快递单格式正确；送错人、寄错东西、没有授权，业务照样失败。评估应该看最后送没送对、有没有泄露及出错能否定位。

### 可执行学习任务（先证据后算法）

使用 [可运行评测脚本](../labs/task-evaluation/README.md) 对 15 条合成结果统计各层指标，明确分母和 95% Wilson 置信区间；再给工具网关注入越权与伪造引文，形成 error taxonomy。

**失败注入 / 负例：** 反例：只统计成功的合法工具调用而丢弃失败样本；同题的训练变体进入 test；引用存在却不支持具体断言；样本只有 10 条就宣布生产准确率。
