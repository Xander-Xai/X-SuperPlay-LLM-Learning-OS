## V3 深入：按当前需求直达本模块（不用先学完前面所有章）

**真实触发：** GRPO Reward 上涨、独立任务正确率没涨时应该怎样定位？

### 机制：专业定义与输入/输出

在同一个 Prompt 下抽多条候选，用组内奖励构建 Advantage 更新策略。GRPO 是优化算法；RLVR 指使用可验证奖励的训练机制，两者不在同一分类层。某实现中的 KL beta 可为零，不能默认所有 GRPO 都加载 Reference。

### 大白话：它为什么有用

一个班集体按班内相对成绩给反馈：如果所有人都同分，就没有有效比较信号。奖励函数若只表扬答案格式，所有人可能学会格式却没学会解题。

### 可执行学习任务（先证据后算法）

先跑 [DPO/GRPO 数学试验](../labs/preference-rl-math/README.md) 手算 group std/无奖励区分，再做不更新模型的 reward 检验；仅在奖励验证器可信后启动 TRL Qwen 0.6B + LoRA 的小预算训练。

**失败注入 / 负例：** 反例：group 内全部同分；答案在 prompt 泄漏；输出越长越高分；只有格式奖励，没有正确性奖励；GPU OOM 时错误归因给算法。
